# KFC Maroc - Site web

Projet personnel réalisé en 2023, avant mon entrée en licence informatique.

L'idée était de créer un site web pour KFC Maroc, qui ne disposait pas encore de son propre site à cette époque. J'ai donc imaginé et développé un site permettant de présenter l'enseigne, ses produits et ses restaurants au Maroc.

## Fonctionnalités

Le site est composé de plusieurs pages :

- **Accueil :** présentation de l'enseigne.
- **Menu :** présentation des différents produits.
- **Histoire :** présentation de l'histoire de KFC.
- **Témoignages :** affichage d'avis clients.
- **Restaurants :** consultation des restaurants selon les villes proposées.
- **Contact :** formulaire permettant de contacter l'enseigne.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript

## Lancer le projet

Aucune installation n'est nécessaire.

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/ghizlaneaissaoui/kfc-homepage.git
   ```

2. Ouvrir le fichier `index.html` dans un navigateur.

## Ce que ce projet m'a apporté

C'était l'un de mes premiers projets en développement web. Je l'ai réalisé en autodidacte, avant même de commencer mes études en informatique.

Il m'a permis de découvrir HTML, CSS et JavaScript, de comprendre comment organiser un site composé de plusieurs pages et de mettre en pratique mes premières connaissances en programmation.
